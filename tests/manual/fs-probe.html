Thử quyền ghi file (File System Access API)

Cách thử

  1. Bấm 1. Chọn file thử, lưu file thu-quyen.txt vào đâu cũng được.
  2. Bấm 2. Ghi lại vài lần: nội dung file đổi theo giờ hiện tại.
  3. Tắt hẳn trình duyệt (mọi cửa sổ), mở lại trang này. Bấm 2. Ghi lại: nếu trình duyệt hỏi quyền, ghi lại các lựa chọn nó đưa ra, rồi chọn “Cho phép mọi lần truy cập” (Allow on every visit) nếu có.
  4. Tắt trình duyệt lần nữa, mở lại, bấm 2. Ghi lại: lần này có hỏi không?
  5. Bấm Sao chép kết quả và gửi lại.
